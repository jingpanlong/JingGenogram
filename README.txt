景·谱 1.5.0 · 界面升级与回收区永久删除

一、统一界面设计
保留用户确认的「家谱＋家族树」绿金 Logo。
主界面采用深绿导航、白色品牌栏、浅色工作区，统一圆角按钮、卡片、输入框与页签。
概览页更新统计卡片；数据管理和关于页使用自适应宽度卡片。
表格更新留白、行距、交替底色、选中效果及状态标签，空列表提供空状态提示。
成员、亲缘查询、图谱设置、待办、导入、确认提示等软件窗口统一字体及输入控件。
安装、卸载及其提示界面采用同一配色、Logo 和圆角按钮。
危险操作使用红色，不与普通保存、恢复操作混用。
窗口缩小时工具栏可自动换行，较长表单保持滚动查看。
系统文件选择、打印机等 Windows 原生对话框继续使用系统样式。

二、回收区入口
进入「家谱管理」→「回收区」。
保留原有「恢复选中家谱」，新增「永久删除选中」和「清空回收区」。
把家谱从正常列表「移入回收区」仍只是可恢复的移动，不会立即永久删除。

三、永久删除一份家谱
1. 在回收区选中要删除的家谱。
2. 点击红色「永久删除选中」。
3. 核对家谱名称及删除范围。
4. 手动输入完整家谱名称，必须完全一致。
5. 按钮启用后，点击「永久删除」。
删除范围包括该回收区目录中的成员档案、照片、资料附件、待办和自动备份。
此操作直接删除回收区文件，不移入 Windows 回收站，不能通过本软件恢复。
其他在用家谱及保存在其他目录的导出 ZIP 备份不会被删除。
确认窗口不使用 Enter 快捷键提交；按 Escape 或点击取消可退出。

四、清空回收区
「清空回收区」会显示待删除家谱数量。
需要输入完整确认文字：永久清空回收区。
输入完全匹配后按钮才会启用，批量操作只作用于当前回收区内的家谱。
如果某一份删除失败，之前已经删除的部分不会回滚；软件会提示已完成和剩余数量。

五、删除失败或中断
永久删除前校验回收区编号、目录范围和文件树，不跟随符号链接或目录联接删除。
真正删除前写入删除状态；文件被占用、权限不足等失败时，会保留「未完成删除」记录。
这时不允许把可能残缺的数据作为完整家谱恢复。
关闭占用文件的程序后，可再次点击永久删除，重新输入确认名称并重试。
如果文件已删完而索引记录仍存在，重试可完成记录清理。
只读文件会在确认删除的回收区目录内移除只读标记后删除。
上述处理不代替外部备份；在永久删除前请保留仍需要的独立 ZIP 备份。

三、新建、切换与重命名
「新建家谱」建立一份独立的空白家谱并打开。
「打开 / 切换」或双击列表行打开选中家谱；顶部下拉框也可切换。
「重命名」修改对应家谱标题，不会改变其他家谱。
每份家谱分别保存成员、头像、资料附件、大事记、待办、上一次保存和自动备份。
不同家谱的成员不会自动互相关联。编辑窗口打开期间不可从背后切换家谱。
新建或载入示例不再清空当前家谱，而是新增另一份家谱。

四、复制与 ZIP 新增
「复制」复制选中家谱的当前档案、任务、事件和使用中的附件，输入新名称后打开副本。
副本有独立目录，修改副本不会修改原家谱；不复制原家谱的历次备份。
「从 ZIP 新增」把完整备份恢复成一份新家谱，不覆盖已有家谱。
「备份选中」只备份选中的这一份家谱，包含当前引用的头像和附件。
原「数据管理」中的导入、按编号更新或 ZIP 恢复仍作用于当前家谱，操作前请核对顶部名称。
如果想把另一份备份加入软件，优先使用家谱管理中的「从 ZIP 新增」。

五、回收区
「移入回收区」将家谱从列表移除并保留其文件，不进行永久删除。
移除当前家谱时会先检查可切换的另一份家谱，再切换过去。
「回收区」页签可选中并恢复，恢复后重新出现在全部家谱列表中。
至少保留一份家谱；要移除最后一份，请先新建一份空白家谱。
1.5 已新增永久删除和清空回收区，操作方法以 1.5 说明为准。

六、旧版自动接入
仍使用 %LOCALAPPDATA%\JingFamily 作为总目录。
若检测到原位置的 family.xml，首次启动会把它登记为「原家谱」，不移动或重写该数据文件。
新建家谱位于 families\编号，各自包含 family.xml、media、backups 等内容。
library.xml 保存家谱列表和当前家谱；library.xml.previous 保存上一次目录索引。
trash 保存回收区文件，staging 用于新建/复制过程中的文件暂存；失败操作可能保留暂存文件以防误删。
旧的原家谱移入回收区时，只移动该家谱的数据、附件及备份，不会移动总目录中的其他家谱。
从回收区恢复原家谱后，它会作为一份新的独立目录家谱进入管理。
未启用旧版数据时，第一次启动会自动建立一份空白家谱。
升级后请使用 1.4 或更新版本管理；旧版软件不认识多家谱目录索引。

七、数据备份与异常恢复
家谱管理的「打开总目录」可查看所有家谱和目录索引。
数据管理中的「打开数据目录」只打开当前家谱目录。
若要搬迁全部家谱，可关闭软件后完整复制总目录，或分别导出每份家谱的 ZIP 后在另一电脑新增导入。
卸载保留整个数据总目录，包含所有家谱及回收区。
目录索引异常时软件不会自动重建并覆盖旧索引；请先复制总目录留存，再检查 library.xml.previous。
如果某家谱的数据文件缺失，切换会失败并保留当前家谱；列表会显示读取错误。
新增、复制、删除、恢复采用目录及索引校验，失败时尽量回退；仍建议另存独立磁盘备份。
--data-dir 参数在 1.4 中指定的是家谱管理总目录，而非某个已登记家谱的子目录。

三、功能说明
【家谱概览】成员统计、性别人数、未录父母人数、事件数、家族简介、生日提醒、字辈及籍贯分布。
生日提醒按公历计算，须填写完整出生日期且未填写去世日期；2 月 29 日在平年按 2 月最后一天计算。
未填去世日期不等同于软件能够确认人物在世，请自行维护档案。
【成员档案】新增、编辑、删除；姓名、性别、生卒、籍贯、字辈、父母、多位配偶、住址、联系方式、职业、生平、头像。
配偶是双向关系；软件拦截自己作为亲属、父母重复、亲子循环和直系亲属配偶关系。
删除人物会解除其关系，但保留关联事件及资料，并清除这些记录的成员关联。
支持档案内容搜索、性别筛选，点击表头排序，双击编辑。
日期格式为 YYYY、YYYY-MM 或 YYYY-MM-DD；未知可以留空。
【亲缘路径】在概览页选择「亲缘路径查询」，选择两人，显示由父母、子女、配偶连接的最短关系链。
路径显示关系步骤，不自动推断各地习俗中的复杂亲属称谓。
【世系图谱】自动分代布局、选中成员、双击编辑、缩放、重置、祖先及后代视图、PNG 导出、系统打印。
金色虚线表示同层配偶，实线表示父母与子女。复杂关系可能出现线条交叉。
祖先及后代视图仅显示对应直系成员；全部视图包含全部成员。
大型图片导出设有像素上限，超限时请选择中心成员及祖先/后代视图。
打印将当前图谱缩放至一页；可选择系统已安装的 Microsoft Print to PDF 等 PDF 打印机。
【家族大事记】添加、编辑、删除事件，填写日期、标题、地点、关联成员及记录。
【资料收藏】添加照片、文献等任意格式附件，修改标题、成员关联及来源说明；打开、另存、移除记录。
附件复制到软件的数据目录，不依赖原文件继续存在。单个附件最大 100 MB。
打开附件需要对应的系统程序；仅打开来源可信的附件。
删除资料记录、移除头像后，原已复制文件可能保留在本地；完整备份只打包当前引用的文件。
【关于软件】介绍软件、功能及数据说明，展示作者平台名称，支持复制名称；未虚构二维码或账号链接。
快捷键：Ctrl+N 添加成员；Ctrl+F 搜索成员；成员页面 F2 编辑。

四、导入、导出和备份
ZIP 完整备份：包含全部档案、事件、资料记录、头像、附件。迁移电脑优先用此格式。
完整备份附件总量上限为 512 MB。导出先写临时文件，成功后才替换同名备份。
恢复会检查关系、日期、路径及附件完整性，再替换当前家谱。
JSON：导出结构化档案及文件引用，不包含文件本体。
JSON 导入会替换当前家谱，并清除头像及资料记录；要保留附件必须恢复 ZIP。
CSV：导出成员名册，包含联系方式、住址；适合表格软件查看。使用下载的专用 CSV 模板可导入；本功能导出的成员名册不直接作为导入模板。
GEDCOM：以 UTF-8 编码读写 5.5.1 基础人物及家庭关系。
支持姓名、性别、生卒、父母、配偶、备注和软件自身的籍贯扩展。
不支持的日期表达、历法、采纳关系、引用来源、其他自定义字段等不会完整保留。
GEDCOM 用于基础信息交换，不替代完整 ZIP 备份。
HTML 家谱册：生成可浏览、带成员索引、亲缘列表、生平和事件的独立网页文件。
不包含住址、联系方式及附件，可在浏览器内打印或保存为 PDF；发布前仍请审阅全部内容。
导入 JSON、GEDCOM、恢复 ZIP、新建空白及载入示例都会替换当前家谱，不是合并导入。
若当前有成员、事件或资料，替换前自动创建完整 ZIP 备份。
软件支持单份家谱最多 20,000 位成员；大型复杂家谱的布局与查找可能较慢，建议按支系管理。

五、数据位置与恢复
数据目录：%LOCALAPPDATA%\JingFamily
主数据：family.xml
上次保存：family.xml.previous
附件：media
替换前自动备份：backups
数据管理页可打开这些目录及检查档案、关系和附件是否完整。
软件会在每次提交编辑时保存；编辑表单内尚未点击保存的内容不会写入档案。
建议将完整 ZIP 另存一份到其他磁盘或可信存储，软件本身不提供云同步或加密。
如果主数据损坏而无法启动：先复制整个数据目录留存，再将 family.xml.previous 的副本改名为 family.xml。
或者将损坏的 family.xml 改名留存，启动空白软件，使用「恢复 ZIP 备份」。
卸载默认保留上述数据目录，重新安装后可继续使用。
备份和导出可能含有个人隐私，请征得亲属同意后录入、妥善保存和分享。

景·谱 1.3.0 新增功能说明

一、亲属快捷添加
进入「成员档案」，选中当前成员，点击「添加亲属」。
支持父亲、母亲、配偶、儿子、女儿、兄弟、姐妹。
添加子女时选择当前成员作为父亲或母亲；不会自动推测另一位父母。

二、编修工作台
新增独立导航页，包含五个页签：
【待补全档案】列出缺少出生日期、籍贯、字辈、生平、父母关系的成员。
  可直接编辑或导出 CSV 清单。未知信息可留空，不需要为了完整而填写不确定内容。
【日期核查】提示未来的出生/去世日期、父母生育年龄疑点。
  年龄阈值只用于提示人工核实，不判定史料真实性，也不自动改动日期。
【重复档案核查】按同名及去掉空格后相同的姓名列出候选。
  同名可能是不同人；必须人工确认，软件不会自动合并。
【生日与忌日】按公历列出未来 30 天、90 天或一年的提醒，支持 CSV 导出。
  需完整日期；填了去世日期的成员只显示忌日，否则按出生日期显示生日。
  2 月 29 日在平年取 2 月最后一天。只在软件页面展示，不提供后台推送。
【编修待办】记录采访、查证、扫描资料等工作，支持成员关联、截止日、说明、完成/重开和删除。
  过期且未完成的任务标注逾期，待办包含在 XML、JSON 和完整 ZIP 备份中。

三、重复档案合并
在重复核查页选择「核实并合并」，选定保留档案和另一份档案，先查看合并预览。
保留档案的非空信息优先；空字段会补入另一份内容。
字段不一致会在生平中保留差异记录，两份不同生平亦会合并保留。
父母、子女、配偶、事件、资料和待办引用会转移到保留档案。
两张不同头像会保留主头像，并将另一张加入资料收藏。
直接亲子/祖先后代或配偶之间不允许直接合并；可能形成循环等错误的结果也会拦截。
确认合并前会自动创建完整 ZIP 备份。合并不代表软件验证两人确为同一人。

四、批量完善档案
在工作台选择「批量完善档案」，勾选成员，可统一填写字辈、籍贯或职业。
默认只填空白字段；勾选覆盖后才修改原已有内容。
支持全选、全不选，保存前再次确认并创建完整备份。

五、导出可编辑 Excel 与按编号更新
工作台或数据管理 → 导出可编辑表格 → 在 Excel 修改 → 上传/导入文件 → 按原编号更新。
导出表格含当前所有成员、内部编号及亲属编号，保持文本格式并支持继续编辑。
更新时保留原成员编号、头像、关联事件、资料和待办。
空白字段会清空相应原内容；删除表格中的一行不会删除软件里该成员。
请不要修改编号。表格里的亲属编号仍需引用同一份表内的成员。
删除配偶关系时需清空双方对应单元格，否则会根据另一方的引用补回双向关系。
未知编号会拦截更新；新建成员请使用空白模板并选择追加。
更新前会显示预览并自动备份。追加模式仍会增加新成员，不会按同名自动覆盖。
可编辑表格包含联系方式和住址，请妥善保存。

六、恢复上次保存
工作台选择「恢复上次保存」，恢复 family.xml.previous。
这是最近一次保存的档案状态，不是无限步撤销；再次恢复可能切换回刚才的版本。
恢复前会校验引用的附件，并创建当前内容的完整备份。
更早的内容请使用数据管理中的 ZIP 备份恢复。

七、升级与兼容
新版继续使用原数据目录，无需重新导入旧家谱。
可以读取旧数据格式，保存后升级到版本 2，以存储新增待办。
保存后的文件请使用景·谱 1.2 或更新版本打开；旧软件会拒绝该数据版本，避免静默丢失新增信息。
升级前仍建议保留一份完整 ZIP 备份。程序未联网、未更改作者联系信息和内置模板能力。

景·谱 1.3.0 · 世系图谱升级说明

一、排版与视觉
重新设计家庭组布局：同层配偶、共同父母优先分组，分支按子树宽度分配空间。
父母先汇聚到家庭连接点，再分支连接子女，减少重复连线；配偶使用虚线及双环标记。
提供「玉笺·绿金」「黛青·深色」「墨印·黑白」三套主题。
采用圆角卡片、轻阴影、分层背景、家谱标题、家训、图例及成员/层级数量。
相对层级使用 01、02 等编号，不代表传统族谱中的绝对世次。
复杂多配偶、交叉亲缘可能出现跨层或交叉连接。若家庭合并分组形成层级冲突，会回退到独立分层，避免丢失成员或形成无穷循环。

二、人物卡片
默认详细模式，显示姓名、性别、字辈、职业、生卒日期、籍贯、子女/资料数及生平状态或计算年龄。
生卒完整时年龄按日期计算周岁，只有年份等部分日期时标注约数。
未知去世日期不会自动推断人物是否在世。
无照片时以姓氏首字作为头像；可在「样式 / 内容」中打开档案照片。
照片按中心裁切显示，不修改原始附件文件。
提供紧凑模式，保留姓名、性别、可选字辈职业和一行日期/籍贯。
长内容在卡片中省略；姓名、父母、配偶、籍贯职业等可悬停查看，双击打开成员编辑。

三、浏览与范围
下拉框可输入姓名并选择具体成员，同名人物可用出生日期及编号区分。
支持全部成员、祖先、后代、近亲四种视图。
近亲包含当前成员、父母、配偶、子女、共享至少一位父母的兄弟姐妹。
「样式 / 内容」可限制 1–8 层或不限制。全部视图按相对层级截取；祖先/后代按亲子距离计算范围。
分支可选择包含或排除配偶；包含配偶时会在主亲子范围之外加入一层配偶成员。
右键成员可快速转到其祖先/后代，或收起/展开直系后代。
收起后代只隐藏该成员的直系后代，其他姻亲可能继续显示；「展开全部」恢复收起的分支，不取消层数限制。
支持姓名定位、适合窗口、放大/缩小、100%、空白处拖动平移、Ctrl+滚轮缩放。
适合窗口会居中显示，完整视图很大时卡片会缩小，可放大查看详细文字。
样式选项在当前软件运行期间切换页面后保留；关闭软件后恢复默认。

四、SVG 矢量导出
导出当前视图，包括主题、字段、范围及收起状态，不导出选中高亮。
文字、卡片、连线均为矢量，文字可选取和编辑；SVG 内按成员分组并含悬停信息。
可在浏览器及支持 SVG 的矢量设计软件中打开；不要求安装第三方设计软件。
字体未嵌入，使用「Microsoft YaHei UI」及回退字体，其他设备字体不同可能导致少量字形差异。
不开启照片时，SVG 不含位图；开启照片时照片以 PNG 内嵌，不依赖原文件路径。
矢量并不表示照片也能无损放大。需要纯矢量文件时请关闭照片。

五、EMF、PNG 与打印
EMF：导出 Windows 增强型图元文件，适合支持 EMF 的文档、演示和排版软件；文字及图形保留绘图指令，照片仍为位图。
高清 PNG：以 2 倍图谱坐标输出。透明 PNG：原尺寸输出透明画布，保留卡片填充及已开启的分层背景。
PNG 设有像素和边长上限，超大图请限制层数、选择分支，或改用 SVG。
整图打印：将当前图谱缩放到一页。可选系统已经安装的 PDF 打印机生成 PDF。
分页打印：按图谱绘图坐标逐块平铺到多页，最多 200 页；超过上限请缩小范围。
软件未捆绑 PDF 打印驱动，也不提供直接编辑 PDF 的功能。

六、交互网页导出
生成独立 HTML 文件，内嵌同一张 SVG，不依赖外部脚本、资源或互联网。
浏览器中支持滚轮和按钮缩放、拖动平移、全图复位、输入姓名定位、打印。
姓名定位优先取首个完全匹配的成员，其次取首个部分匹配成员；同名时可能定位到首个结果。
网页只包含导出时的图谱，不会读取或修改软件家谱。修改家谱后需重新导出。
分享前请检查图谱中姓名、照片和生卒等信息是否适合公开；默认不导出联系方式、住址或生平正文。
